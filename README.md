## Core Highlights & Business Architecture

- **100/100 Lighthouse Speed Score:** Zero heavy frameworks or runtime overhead. Built with semantic HTML5, modern CSS3 custom properties, and vanilla ES6+ JavaScript.
- **Mobile-First Responsive Layout:** Seamlessly adapts across smartphones, tablets, laptops, and ultra-wide displays.
- **Interactive Checkout & Ordering Modal:** Dynamic cart calculations, item customization, and multiple payment methods:
  - **bKash & Nagad** (Instant mobile financial service routing with transaction ID capture)
  - **Credit / Debit Cards** (Visa, Mastercard, American Express)
  - **Cash on Delivery / In-Store Pickup**
- **Direct WhatsApp Business Dispatch:** Formats order details, customer contact, and delivery preferences into a structured text dispatch for the cafe's WhatsApp business channel.
- **Interactive Location & Inquiries:** Branded Google Maps embed, real-time operating hours, and inquiry form.
- **Enterprise Security & DOM Sanitization:** Strict context escaping (`textContent` + `encodeURIComponent`), secured external links with `rel="noopener noreferrer"`.
